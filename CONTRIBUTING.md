# Contributing to Indy

Thanks for taking an interest in Indy. Bug reports, ideas, and questions are all welcome, and
[issues](https://github.com/liamdmcgarrigle/indy-artifacts/issues) are the place for them. I read
every one.

## Please don't open a pull request

Indy is a one-person project, and I don't have time to review code I haven't asked for.

If you want to change something, open an issue and talk it through with @liamdmcgarrigle first.
If we agree on it there and I ask for a pull request, go ahead and link the issue in it.

Pull requests that don't come out of a conversation like that are closed automatically. It's the only way one person can keep up in this new AI world.

## Reporting a bug

Say what you did, what you expected, and what happened instead. Include the image tag you run and
whether you use Docker or Podman. Screenshots help.
